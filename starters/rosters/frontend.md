# Frontend Role

Optimized for frontend engineering work: component architecture, visual design review, accessibility compliance, browser performance, and end-to-end testing.

## Included Skills

- **design-review** — Visual hierarchy, responsive design, interaction patterns (requires Playwright)
- **accessibility-audit** — WCAG 2.1/2.2 compliance, keyboard navigation, screen reader compatibility
- **e2e-testing** — Playwright test scaffolding, Page Object Model, CI integration
- **typescript-patterns** — Type system, error handling, async patterns
- **performance-optimization** — Bundle size, rendering performance, memory leaks
- **code-review** — General code quality via Pragmatic Quality framework

## Deliberately Excluded

- Database schema design, API design, infrastructure — use the `backend` or `infra-engineer` role
- Security-specific review — use the `security-sentry` role
