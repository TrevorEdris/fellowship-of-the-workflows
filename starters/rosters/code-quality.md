# Code Quality Role

Optimized for code quality improvement: thorough reviews, systematic refactoring, performance analysis, test coverage, and AI slop removal.

## Included Skills

- **code-review** — Pragmatic Quality framework, PR-level review
- **refactoring** — Smell detection, safe transformations, test-verified execution
- **performance-optimization** — N+1 queries, complexity analysis, memory leaks
- **e2e-testing** — Playwright scaffolding, Page Object Model, CI integration
- **test-driven-development** — RED-GREEN-REFACTOR enforcement
- **systematic-debugging** — Root cause analysis methodology
- **desloppify** — AI slop detection and removal

## Deliberately Excluded

- Domain-specific skills (API design, IaC, security) — combine with other roles as needed
