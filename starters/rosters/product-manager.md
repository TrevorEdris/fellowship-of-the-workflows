# Product Manager Role

Optimized for product management: structured PRD authoring, requirements validation, design exploration, and extracting requirements from existing codebases.

## Included Skills

- **prd-author** — Interactive PRD creation and iteration with facilitation prompts
- **prd-validator** — Format enforcement for PRDs (scoring, PASS/FAIL gating)
- **brainstorm** — Structured design thinking for product decisions
- **reverse-engineer** — Extract requirements and PRDs from existing codebases

## Deliberately Excluded

- Implementation skills (TDD, refactoring, code review) — use engineering roles
- Infrastructure/IaC — use the `infra-engineer` role
- Security review, performance optimization — use the `code-quality` or `security-sentry` role
