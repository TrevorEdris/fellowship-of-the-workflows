# Backend Role

Optimized for backend engineering: API design, data modeling, system architecture, language-specific patterns, and test-driven development.

## Included Skills

- **api-design** — REST/GraphQL endpoint design, OpenAPI specs, versioning
- **database-schema-designer** — Normalization, indexing, migration patterns
- **system-design** — Distributed systems, resilience patterns, scalability
- **code-review** — General code quality via Pragmatic Quality framework
- **performance-optimization** — N+1 queries, algorithmic complexity, caching
- **go-patterns / python-patterns / rust-patterns** — Language-specific idioms
- **systematic-debugging** — Root cause analysis methodology

## Deliberately Excluded

- UI/UX review, accessibility auditing — use the `frontend` role
- Infrastructure/IaC — use the `infra-engineer` role
