## Scan Results

### Claude / Anthropic

**Model changes**
- Opus 4.6 is now the standard model; Opus 4.0/4.1 removed (auto-migrated). Default effort set to medium for Max/Team subscribers. Output token ceiling raised to 64k (default) / 128k (upper bound). 1M context unlocked for Opus 4.6 on Max/Team/Enterprise plans. (v2.1.68–v2.1.77)
- "ultrathink" keyword re-introduced to force high effort on next turn. (v2.1.68)

**New skill / agent frontmatter fields**
- `effort` field for skills and slash commands — overrides model effort level at invocation (low/medium/high). (v2.1.80)
- `initialPrompt` frontmatter for agent definitions — agent auto-submits first turn on launch. (v2.1.83)
- `effort`, `maxTurns`, `disallowedTools` frontmatter for plugin-shipped agents. (v2.1.78)

**Hook system expansions**
- Conditional `if` field on hooks using permission rule syntax to filter execution. (v2.1.85)
- New hook events: `TaskCreated`, `CwdChanged`, `FileChanged`, `StopFailure`, `PermissionDenied`, `InstructionsLoaded`, `PostCompact`, `Elicitation`, `ElicitationResult`. (v2.1.76–v2.1.89)
- `defer` decision added to `PreToolUse` hooks; headless sessions can pause/resume with `--resume`. (v2.1.89)
- `PreToolUse` hooks can satisfy `AskUserQuestion` by returning `updatedInput`. (v2.1.85)

**MCP improvements**
- MCP elicitation support — servers can request structured input mid-task via dialog. (v2.1.76)
- MCP OAuth RFC 9728 compliance. Tool descriptions capped at 2KB. (v2.1.85)

**Automation / scheduling**
- `/loop` command for recurring prompts/slash commands on an interval. (v2.1.71)
- Cron scheduling tools within sessions (`CronCreate`, `CronDelete`, `CronList`). (v2.1.71)
- `--channels` research preview for push messaging to phone during sessions. (v2.1.81)

**Security / permissions**
- Security fix: `PreToolUse` "allow" was bypassing `deny` rules — now corrected. (v2.1.77)
- `CLAUDE_CODE_SUBPROCESS_ENV_SCRUB=1` to strip credentials from subprocess environments. (v2.1.83)
- Sandbox silent-disable now shows visible warning. (v2.1.78)

**Other notable**
- Transcript search with `/` in transcript mode. (v2.1.83)
- `worktree.sparsePaths` for sparse-checkout in large monorepos. (v2.1.76)
- Prompt cache invalidation fix — 12x token savings for SDK `query()` calls. (v2.1.72)
- Windows: PowerShell tool (opt-in preview). (v2.1.84) [BETA]
- VSCode: `/remote-control` bridge, native MCP management dialog. (v2.1.79)

- **Composer 2** (Mar 19): New first-party model; CursorBench 61.3 vs 44.2 for Composer 1.5. Trained on long-horizon coding via RL. Available in app and "Glass" alpha interface. [BETA for Glass]

- **Automations** (Mar 5): Always-on agents triggered by cron, Slack, Linear, GitHub PR, PagerDuty, webhooks. Agents run in cloud sandboxes with memory for iterative improvement.
- **JetBrains IDE Support** (Mar 4): Cursor available in all JetBrains IDEs via Agent Client Protocol.

### Finding 3: Conditional `if` field on hooks

## Impact Assessment

### New Feature: Conditional hook execution via `if` field
- **Tool:** Claude Code
- **Date:** 2026-03-26 (v2.1.85)
- **Release stage:** stable
- **What changed:** Hook entries in hooks.json can now include an `if` field using permission rule syntax to gate execution. This allows hooks to fire only when certain conditions are met (e.g., specific file patterns, directories) without needing to do the filtering inside the hook script.
- **Project impact:**

  - [ ] New workflow needed?
  - [ ] Configuration change needed?
- **Recommendation:** Monitor. Existing hooks work fine without `if` conditions. Consider adding `if` conditions to `protect-secrets.js` and `block-dangerous-commands.js` to reduce overhead on non-applicable calls.
- **Priority:** medium
- **Affected files:** `hooks/hooks.json`

### Finding 4: New hook events (`TaskCreated`, `CwdChanged`, `FileChanged`, `PostCompact`)

## Impact Assessment

- **Date:** 2026-03-12 to 2026-04-01 (v2.1.76–v2.1.89)

  - [ ] Configuration change needed?
- **Recommendation:** `PostCompact` is immediately useful — fire `context-snapshot.js` after compaction, not just before. `TaskCreated` enables orchestration audit hooks. Low urgency; monitor adoption.
- **Priority:** medium
- **Affected files:** `hooks/hooks.json`, `hooks/context-snapshot.js`
