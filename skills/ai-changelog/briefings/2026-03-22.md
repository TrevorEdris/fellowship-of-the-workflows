### New Feature: `effort` frontmatter for skills
- **Tool:** Claude Code
- **Date:** March 19, 2026 (v2.1.80)
- **What changed:** Skills and slash commands can now declare an `effort` level (`low`, `medium`, `high`) in their frontmatter. This controls compute intensity — higher effort means more thorough but slower execution. Also added `/effort` slash command (v2.1.76) and effort display in UI spinner.
- **Project impact:**
  - [x] Existing workflow update? Which: `skills/orchestrate/SKILL.md`
  - [ ] New workflow needed?

- **Recommendation:** Add `effort: high` to `orchestrate` (multi-step, multi-agent coordination). Consider `effort: medium` for analysis skills like `ai-changelog`, `security-review`, `code-review`.
- **Priority:** high
- **Affected files:** `skills/orchestrate/SKILL.md`, optionally `skills/ai-changelog/SKILL.md`, `skills/security-review/SKILL.md`, `skills/code-review/SKILL.md`
