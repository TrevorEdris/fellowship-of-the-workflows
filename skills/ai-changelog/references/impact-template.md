# Impact Assessment Template

Use this template for each significant finding.

```markdown
## Impact Assessment

### New Feature: [feature name]
- **Tool:** [which AI coding tool]
- **Date:** [when announced/released]
- **What changed:** [1-2 sentences]
- **FOTW impact:**
  - [ ] New skill needed?
  - [ ] Existing skill update? Which: ___
  - [ ] New rule needed?
  - [ ] Agent update needed?
  - [ ] Hook update needed?
  - [ ] No action needed
- **Recommendation:** [specific action or "monitor"]
- **Priority:** [high/medium/low]
- **Affected workflows:** [list specific skill/rule/agent names]
```

## Priority Guidelines

- **High:** Feature directly obsoletes or breaks an existing FOTW workflow, or enables a capability we've been wanting
- **Medium:** Feature improves a workflow we already have, or opens new possibilities worth exploring
- **Low:** Informational only, no immediate FOTW impact
